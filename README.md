# backtester1 — 한국 주식 팩터 연구 백테스터

한국 주식에서 **거래비용을 넘는 롱온리 우위가 있는지**를 검증하는 도구입니다.
전략을 만들어 성과를 자랑하는 프로젝트가 아니라, **그럴듯해 보이는 신호를 기각하는**
프로젝트입니다.

지금까지 다섯 개 가설을 검정했고 넷을 기각했습니다. 기각된 것들은 처음엔 모두
유의해 보였습니다 — 도구의 가치는 거기에 있습니다.

## 지금까지의 결과

| 가설 | 처음 본 값 | 파고든 뒤 | 판정 |
|---|---|---|---|
| 평균회귀(반전) | 인샘플 t 2.23 | OOS에서 **부호 반전** | 기각 |
| 저변동성 | IC t 3.14 | 롱온리 초과 t −0.13 (관측 202개) | 기각 |
| 내부자 매수 | t 3.12 | 공시 서류 이벤트 제거 시 t 0.51 | 기각 |
| 소형주 | 인샘플 t 4.00 | OOS t −0.13 (국면 효과) | 기각 |
| **PEAD (실적 서프라이즈)** | **롱온리 초과 연 13.4%, t 2.42** | 진단 통과, 전반부는 약함 | **미확정** |

네 번의 기각에는 공통점이 있습니다. **"신호가 없다"가 아니라 "우리가 생각한 것과 다른
것을 재고 있었다"**였습니다. 반전은 시장 국면을, 저변동성은 하위 종목의 부진을,
내부자는 신규선임 서류를, 소형주는 2018~2022 국면을 재고 있었습니다.

자세한 수치와 판단 근거는 [`experiments/log.md`](experiments/log.md)에 시간순으로
기록돼 있습니다.

## 도구가 정상임을 어떻게 아는가

모든 것을 기각하는 도구는 정확한 것일 수도, 아무것도 못 잡는 것일 수도 있습니다.
셋으로 확인했습니다.

1. **인공 신호 검정력** (`run_power_check.py`) — 강도를 아는 신호를 실제 데이터에
   심어놓고 찾아내는지 셉니다. 현재 표본(비겹침 관측 204개)에서 IC 0.02를 95%,
   0.03을 100% 검출합니다.
2. **미국 팩터 재현** (`run_french_validation.py`) — Ken French 100년 데이터에서
   모멘텀·규모·가치를 문헌과 같은 방향·크기로 검출합니다(모멘텀 단조성 1.00, t 4.83).
3. **표본 확장 후 재현** — 데이터를 2010년까지 늘려 관측을 3배로 만든 뒤에도
   저변동성 기각이 그대로 재현됐습니다.

동시에 2번은 **검정력의 한계**도 알려줬습니다. 모멘텀처럼 견고한 팩터조차 5년 구간에서는
37%만 검출됩니다. 그래서 이 프로젝트는 유의하지 않은 결과를 "없다"로 읽지 않고
**"이 표본으로 볼 수 있는 크기가 아니다"**로 구분해 기록합니다.

## 방법론에서 지키는 것

- **Look-ahead 방지**: 신호는 t일에 만들고 t+1일에 체결합니다. 재무·공시 데이터는
  회계기간이 아니라 **실제 공시일** 기준으로만 사용합니다. 테스트로 강제합니다
  (미래 가격을 바꿔도 과거 포지션이 불변인지 검증).
- **시점별 유니버스**: 매 분기 그 시점의 실제 시가총액 상위 N종목을 씁니다. 고정
  티커 목록은 '오늘 살아남은 종목'이라 생존편향이 들어갑니다. DART 수집 대상도
  같은 이유로 유니버스에 한 번이라도 편입된 종목 전체(466개)로 잡았습니다.
- **비겹침 샘플링**: 20일 forward return을 매일 재면 인접 관측이 거의 같은 정보를
  담아 t-stat이 부풀려집니다. 호라이즌 간격으로 띄워 셉니다.
- **롱온리 관점**: 공매도를 하지 않으므로 IC(전체 순위상관)가 아니라 **상위 분위가
  유니버스 평균보다 나은가**로 판단합니다. 예측력이 하위 구간에 몰려 있으면 IC는
  좋아도 살 수 있는 게 없습니다 — 저변동성이 정확히 그 경우였습니다.
- **현실적 비용**: 수수료 + 슬리피지 + 시장충격(참여율 기반) + **증권거래세**
  (매도분에만, 연도별 세율 반영). 저변동성에서 비용 전 우위 1.88%p 중 74%가
  비용으로 사라진 전례가 있습니다.
- **기업행위 보정**: Open API 종가는 액면분할이 보정돼 있지 않습니다(삼성전자
  2018-05-04이 −98% 수익률로 잡힘). 상장주식수 변화로 분할을 판별해 보정합니다.
- **다중검정 인식**: 40건 넘게 검정한 상태라 우연히 t 3이 나오는 게 정상입니다.
  새 가설은 **측정 방식과 판정 기준을 먼저 못박고 한 번만** 봅니다.

## 데이터

| 종류 | 출처 | 범위 |
|---|---|---|
| 전종목 시세·시가총액 | **KRX Open API** (인증키 + 서비스 승인) | 2010-01-04 ~ 현재, 3,677종목 |
| 분기 재무제표 | DART OpenAPI | 2015~2024, 408종목 |
| 검증용 팩터 수익률 | Ken French 라이브러리 | 1926~ (미국) |

> **KRX 접근에 관하여**: 초기에 pykrx로 `data.krx.co.kr`을 스크래핑하다 이용약관
> 위반으로 계정이 차단된 적이 있습니다. 그때 KRX 안내문이 직접 권한 정식 경로가
> Open API였고, 지금은 그쪽만 씁니다. 수집 스크립트는 pykrx를 import하지 않습니다.

API 키는 프로젝트 루트의 `*.env` 파일에 두고 git에 올리지 않습니다:

```
KRX_API_KEY=...
DART_API_KEY=...
```

## 설치와 실행

```bash
pip install -r requirements.txt
```

데이터 수집 (순서대로, 중단해도 재실행하면 이어받습니다):

```bash
python scripts/collect_openapi_panel.py
```

```bash
python scripts/collect_dart_fundamentals.py
```

분석:

```bash
python scripts/run_pead_test.py
```

도구 검증:

```bash
python scripts/run_power_check.py
```

테스트:

```bash
python -m pytest tests/ -q
```

## 구조

```
config/settings.py          # 유니버스 크기, 호라이즌 등 공통 설정
src/
  data_loader/
    krx_openapi.py          # KRX Open API (정식 채널) + 보정된 종가 패널
    price_adjust.py         # 액면분할/병합 보정
    universe.py             # 시점별 시가총액 유니버스
    dart_loader.py          # DART 재무제표 (공시일 보존)
    french_loader.py        # 검증용 미국 팩터 데이터
    krx_panel.py            # pykrx 기반 거래일 달력 (openapi 달력의 교차검증용)
  features/
    earnings_surprise.py    # SUE / PEAD
    multi_source.py         # 가격·규모 팩터, 중립화
  research/
    ic_analysis.py          # cross-sectional IC
    quantile_analysis.py    # 롱온리 분위 분석
    power_analysis.py       # 검정력 (신호 주입)
  costs/cost_model.py       # 수수료·슬리피지·시장충격·거래세
  portfolio/                # 포트폴리오 백테스트 엔진
  reporting/metrics.py      # CAGR, Sharpe, MDD
experiments/log.md          # 시도한 것과 기각 이유 전부
```

`data/`는 재생성 가능한 캐시라 git에 포함하지 않습니다.
